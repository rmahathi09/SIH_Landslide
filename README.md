# AI-Based Early Warning and Landslide Risk Monitoring System in NER

## SIH 2026 Project

### Problem Statement
Development of an AI-based early warning and landslide risk monitoring system for the North Eastern Region (NER) of India.

### Project Overview
This project aims to develop an AI-based system for monitoring and predicting landslide risks using environmental, geographical, and historical data. The system will provide early warnings to help reduce the impact of landslides in vulnerable regions.

### Objectives
- Monitor landslide-prone areas
- Analyze factors contributing to landslides
- Predict landslide risk using AI/ML techniques
- Generate early warnings
- Provide risk information through a user-friendly interface
